# Harishik · Research & Engineering

Responsive, dependency-free portfolio built from the approved v13 research portfolio.

## Features
- Filterable case studies with accessible modal project explorers
- Selectable architecture components and full system diagrams
- Zoomable project photographs and technical evidence
- Expandable experience details and additional projects
- Light/dark theme, keyboard navigation, reduced-motion support
- Original downloadable portfolio PDF

## Local preview
Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## GitHub Pages
Publish this directory at the root of a public repository. Under Settings → Pages, select “Deploy from a branch”, `main`, and `/ (root)`. No paid hosting, build service, API keys, or backend is required.

## Content
Edit `index.html` for biography, experience, publications, and contact. Edit `app.js` for project details, architecture component explanations, and galleries. Styles are in `style.css`. Assets come from the approved portfolio. Photographs, personal content, and project evidence remain the owner's material. No license to reuse these assets is granted here.

Publication status and project claims reflect the approved portfolio snapshot. Review them when updating the site. The railway and institute sections intentionally exclude confidential source code and research data.
